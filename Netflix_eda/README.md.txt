# Netflix Data Analysis (EDA)

##  Objective
To analyze Netflix dataset and extract insights about content trends, genres, and distribution.

## Dataset
Netflix dataset containing:
- Title
- Genre
- Release Year
- Country
- Rating
- Duration

##  Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

##  Project Workflow
- Data cleaning
- Exploratory Data Analysis (EDA)
- Visualization of trends

##  Output
- Content distribution charts
- Genre analysis
- Year-wise trends
- Country-wise content analysis

##  How to Run
1. Open the notebook in Jupyter Notebook
2. Run all cells
3. Explore visual insights

##  Conclusion
The analysis reveals trends in Netflix content, including popular genres and production patterns.
