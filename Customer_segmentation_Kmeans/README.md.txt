# Customer Segmentation using K-Means Clustering

##  Objective
The goal of this project is to segment customers based on their income and spending behavior using K-Means clustering.

##  Dataset
Mall Customers dataset containing:
- Age
- Annual Income (k$)
- Spending Score (1–100)

##  Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

##  Project Workflow
- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Elbow method to determine optimal clusters
- K-Means clustering

##  Output
- Customer segmentation plots
- Elbow method graph
- Cluster visualization with centroids

##  How to Run
1. Open the notebook in Jupyter Notebook
2. Run all cells
3. View the visualizations

##  Conclusion
Customers are grouped into different segments, helping businesses target them more effectively.
