# Student Score Prediction using Machine Learning

##  Objective
This project predicts student scores based on study hours using regression techniques.

##  Dataset
Dataset contains:
- Hours studied
- Scores obtained

##  Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

##  Project Workflow
- Data loading
- Data visualization
- Model training using Linear Regression
- Model evaluation

##  Output
- Scatter plot of study hours vs scores
- Regression line visualization

##  How to Run
1. Open the notebook in Jupyter Notebook
2. Run all cells
3. Check prediction results and graphs

##  Conclusion
The model shows a positive relationship between study hours and student performance.
